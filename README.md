# Shared Expense Splitter (React JS)

A responsive React + Vite shared expense tracker built for a component-based architecture practical.

## Run locally

```bash
npm install
npm run dev
```

Open the localhost URL printed by Vite.

## Features
- Dashboard, Expenses, Groups, and Balances pages using React Router.
- Add and delete expenses, equal or custom splits, create groups, and record settlements.
- Balance calculations via array `map`, `filter`, `reduce`, and object entries.
- State management with `useState`, `useEffect`, and `useMemo`.
- Reusable Card, Modal, Stat, PageHead, ExpenseList, and GroupCard components.
- CSS Modules for the reusable Card component and global responsive CSS for layout.
- LocalStorage persistence and starter sample data.

## Note
This is a frontend-only demonstration. Data is saved to your browser's localStorage, not a server. Existing members are seeded for the demo; it does not provide accounts, invitations, or bank integrations.
